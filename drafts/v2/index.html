Five drafts — pick the closest

Each is a genuinely different design, not a restyle: different base colour, accent, type scale and navigation model. All five show the same five screens — Home, a reading page with citations, the food table & calculator, training stats, and the table of contents. Use the small switcher at the top of each draft to move between screens.
